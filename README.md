# Temperature-Converter

This is a basic Java console program that converts temperatures between Celsius and Fahrenheit

When you run the program it shows two options

1 C to F
2 F to C

You are asked to enter 1 or 2 to choose the conversion direction

If you choose 1 the program asks for a temperature in Celsius and converts it to Fahrenheit using the formula
C × 9 ÷ 5 + 32

If you choose 2 the program asks for a temperature in Fahrenheit and converts it to Celsius using the formula
(F - 32) ÷ 1.8

If you enter anything else the program shows an error message

All code is in Main.java

This program is created for practicing basic user input and math operations in Java
